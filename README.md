# Personal Computer Science & Computing Disciplines Degree

An autonomous, university-degree equivalent curriculum covering Computer Science and related computing disciplines, tracked via an Obsidian-based knowledge vault.

## Vision & Architecture

- **Equivalence:** Modeled after accredited university degree programs with rigorous academic foundations.
- **Credit Model (Studies + Tasks):** Instead of passive seat hours, standard 120 Semester Credit Hours (SCH) per major are reframed into rigorous **Studies** (theory, textbooks, lecture mastery) + **Tasks** (projects, labs, code implementations, problem sets).
- **Obsidian Vault:** Primary knowledge repository for networked thinking, concept synthesis, course notes, and project documentation.

## Disciplines Covered

1. **Computer Science (CS)**
2. **Software Engineering (SWE)**
3. **Computer Engineering (CE)**
4. **Information Systems (IS)**
5. **Business Information Systems (BIS)**
6. **Information Management (IM)**
7. **Information Technology (IT)**
8. **Network Engineering (NE)**
9. **Cybersecurity (Sec)**
10. **Data Science (DS)**
11. **Artificial Intelligence (AI)**
12. **Business Intelligence (BI)**
13. **Human-Computer Interaction (HCI)**
